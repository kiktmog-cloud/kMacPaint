# kMacPaint (Windows 11 mspaint Edition for macOS)

Windows 11 최신 그림판(`mspaint.exe`)의 리소스와 인터랙션을 역공학(REA)하여, **macOS 네이티브(Swift / AppKit / CoreGraphics)** 환경에 100% 동일한 사용감으로 재구현한 맥용 그림판입니다.

---

## 🎨 핵심 구현 기능

### 1. 8방향 전방위 캔버스 리사이즈 핸들 & 실시간 확장 가이드 (좌측/상단 확장 완벽 지원)
* **전방위 8방향 핸들 탑재:** 기존 윈도우 그림판의 우측/하단 한계를 넘어 **좌측(Left), 상단(Top), 우측(Right), 하단(Bottom)** 및 **4개 모서리(좌상, 우상, 좌하, 우하)**까지 총 8개의 8x8px 흰색 핸들이 배치되어 있습니다.
* **좌측 및 상단 캔버스 확장:** 좌측 핸들을 왼쪽으로 당기거나 상단 핸들을 위로 당기면, 기존 그림을 원하는 위치에 안전하게 보존한 채 좌측/상단 방향으로 도화지가 실시간으로 시원하게 늘어납니다.
* **실시간 확장 가이드:** 마우스로 핸들을 잡고 드래그하면 어디까지 확장되는지 선명한 파란색/흰색 이중 점선 가이드(2.5px)와 옅은 반투명 영역이 실시간으로 표시됩니다.
* 새로 늘어난 영역은 2번 배경색(Color 2)으로 자동 확장되며, **실행 취소(`⌘Z`)**를 완벽 지원합니다.
* **수치 직접 입력 여백 확장 지원 (`⌘K`):** 상단 메뉴 `이미지 > 캔버스 크기 및 여백 확장...` 또는 `⌘K`를 눌러 상단/좌측/하단/우측에 추가할 여백을 픽셀 단위로 정확하게 입력하여 확장할 수도 있습니다.
* **이미지 화면 중앙 자동 정렬 (Centering):** 파일 열기(`⌘O`)로 이미지를 불러오거나 새 문서를 열 때 이미지가 작업 화면 한가운데에 보기 좋게 정렬되며, 주변에 여유로운 작업 여백이 확보되어 좌측/상단 핸들을 손쉽게 잡고 확장할 수 있습니다.

### 2. 캔버스 위 인라인 텍스트 & 스마트 서식 리본
* 별도의 팝업창(NSAlert) 없이 캔버스 클릭 위치에 바로 **점선 텍스트 박스**가 생성됩니다.
* **부분 블록 선택 서식 적용 (Rich Text Range Editing):**
  * 마우스로 드래그하여 **블록을 지정한 부분만 개별적으로 색상, 글꼴, 크기, 볼드(`⌘B`), 이탤릭(`⌘I`), 밑줄(`⌘U`)을 각각 다르게 적용**할 수 있습니다.
  * 블록을 선택하거나 커서를 옮길 때마다 서식 리본의 글꼴/크기/스타일/색상 버튼이 해당 글자의 서식 상태와 실시간으로 자동 동기화됩니다.
* **텍스트 밀착 자동 리사이징 & 경계 클램핑:** 입력하는 글자 폭과 줄 수에 8px 여백으로 딱 맞게 텍스트 상자가 쫀쫀하게 늘어나며, 캔버스 우측/하단 경계 인근에서 커밋 시에도 화면에 보이던 줄바꿈과 폭 그대로 비트맵에 정확히 병합됩니다.
* **스마트 플로팅 서식 리본:**
  * **글꼴(Font Family) 선택:** Apple SD 산돌고딕 Neo, Helvetica, Arial, Times New Roman, Courier New, Georgia, Menlo 등 대표 서체 드롭다운
  * **글자 크기(Font Size):** 9pt부터 72pt까지 자유 조절
  * **스타일 토글:** 볼드 `B` (`⌘B`), 이탤릭 *I* (`⌘I`), 밑줄 <u>U</u> (`⌘U`)
  * **글꼴 색상 피커:** 서식 바 내 컬러 웰 및 상단 20색 팔레트 클릭 시 실시간 글자 색상 변경
  * **시스템 서체 패널:** `서체…` 버튼 또는 `⌘T` 단축키로 맥 전체 서체 선택 가능
  * **스마트 경계 스냅:** 캔버스 상단(y < 35)에 입력 시 서식 바가 텍스트 아래쪽으로 자동 전환되며, 우측 경계 안쪽으로 스냅되어 캔버스 밖으로 잘리지 않습니다.
  * **블록 내 `⌘A` 지원:** 텍스트 박스 안에서 `⌘A` 입력 시 입력된 텍스트 전체 블록 지정 가능.
  * 외부 클릭 또는 `Esc` 입력 시 캔버스에 영구 병합(Bake) 및 `⌘Z` 실행 취소 지원.

### 3. 캔버스 확대/축소 (Zoom) & 제스처 지원
* **하단 상태표시줄 줌 컨트롤러:**
  * 윈도우 그림판 스타일의 `[-]` 버튼, 줌 슬라이더 (25% ~ 800%), `[+]` 버튼, 현재 배율 퍼센트 라벨(예: `100%`) 탑재
* **트랙패드 & 마우스 휠 줌:**
  * 트랙패드 두 손가락 핀치-투-줌(Pinch-to-zoom) 제스처 지원 (마우스 커서 중심 확대/축소 및 슬라이더 실시간 연동)
  * `⌘ + 마우스 휠 스크롤` 줌 지원
* **키보드 단축키:**
  * 확대: `⌘ +` (또는 `⌘ =`)
  * 축소: `⌘ -`
  * 100% 원래 크기 복귀: `⌘ 0`

### 4. Shift 정비율 도형 및 45도 각도 스냅
* **타원(Oval):** `Shift`를 누르고 드래그하면 완벽한 **정원(Circle)**으로 그려집니다.
* **직사각형 / 둥근 직사각형:** `Shift`를 누르고 드래그하면 1:1 비율의 **정사각형(Square)**으로 그려집니다.
* **직선(Line):** `Shift`를 누르고 드래그하면 **수평(0°), 수직(90°), 대각선(45°, 135°)** 각도로 자동 스냅(Snap)됩니다.
* 마우스 드래그 도중 `Shift`를 누르거나 떼면 실시간으로 모양이 정비율/자유 비율로 즉시 전환됩니다.

### 5. 선택 도구 (Marquee Selection) & 자유 조절 / 클립보드 편집
* **사각형 선택 (Marquee Drag):** 툴바 첫 번째의 점선 사각형 아이콘(선택 도구)을 선택하고 도화지를 드래그하면, 선명한 파란색 틴트와 흑백 교차 점선(Marching Ants)으로 선택 영역을 지정할 수 있습니다.
* **8개 리사이즈 핸들 & 이동:** 선택 완료 시 영역 주변에 8개의 크기 조절 핸들과 점선 테두리가 활성화됩니다.
  * 내부를 잡고 드래그하면 원하는 위치로 즉시 이동할 수 있습니다.
  * 처음 이동하거나 변형하는 순간 원래 위치는 2번 배경색(Color 2, 기본 흰색)으로 깔끔하게 지워지며 Undo(`⌘Z`)에 기록됩니다.
  * 8개 핸들을 잡아 선택 영역 이미지의 가로/세로/대각선 크기를 자유롭게 확대/축소할 수 있습니다.
* **키보드 미세 이동 (Nudge):** 방향키(←, →, ↑, ↓)를 눌러 1픽셀씩 정밀하게 이동할 수 있으며, `Shift`를 누른 채 방향키를 누르면 10픽셀씩 빠르게 이동합니다.
* **잘라내기(`⌘X`) / 복사(`⌘C`) / 붙여넣기(`⌘V`):**
  * 선택 영역을 `⌘C`로 클립보드에 복사하거나 `⌘X`로 도화지에서 잘라낼 수 있습니다.
  * 잘라낸 자리는 2번 배경색으로 지워집니다.
* **삭제 (Delete / Backspace):** `Delete` 또는 `Backspace` 키를 누르면 선택된 영역이 2번 배경색으로 깨끗이 삭제됩니다.
* **도화지 전체 선택 (`⌘A`):** 텍스트를 입력 중이 아닐 때 `⌘A`를 누르면 캔버스 전체 영역이 한 번에 선택 도구로 묶여 바로 이동하거나 복사할 수 있습니다.
* **병합 (Bake):** 선택 영역 바깥 도화지를 클릭하거나 `Enter`를 누르면 현재 위치와 크기 그대로 캔버스 비트맵에 영구 병합됩니다.

### 6. 외부 이미지 얹기 (플로팅 오버레이 기능)
* `⌘V` (클립보드 붙여넣기) 또는 상단 메뉴 `파일 > 이미지 삽입(얹기)...` (`⌘I`)을 실행하면 다른 이미지를 도화지 위에 바로 얹을 수 있습니다.
* **점선 테두리(Marching Ants)**와 **8개 조절 핸들**이 표시되는 플로팅 상태로 뜹니다.
* 마우스로 원하는 위치로 자유롭게 이동하거나 크기를 조절할 수 있습니다.
* 도화지 바깥을 클릭하거나 `Enter`를 누르면 현재 위치 그대로 메인 캔버스에 영구 병합(Bake)됩니다.

### 7. Windows 11 Paint 원본 SVG 아이콘 및 직관적인 툴바 (선택 도구 눌림 효과)
* Windows 11 `mspaint.exe` 패키지에서 직접 추출한 원본 SVG 에셋(연필, 브러시, 지우개, 페인트통, 스포이드, 도형 등)이 그대로 탑재되었습니다.
* **활성 도구 눌림 효과 (Active Pressed State):** 현재 선택된 도구 버튼이 Windows 11 Fluent 스타일의 부드러운 하늘색 틴트 배경과 1.5px 액센트 블루 테두리, 그리고 1px 물리적 깊이감으로 확실하게 '꾹 눌려있는' 시각적 피드백을 제공합니다.
* **스마트 툴바 동기화:** 도구 버튼 클릭 시뿐만 아니라, 스포이드로 색을 추출한 후 연필로 자동 복귀하거나 이미지를 붙여넣어 선택 모드로 진입할 때도 툴바의 눌림 상태가 실시간으로 자동 연동됩니다.
* **그리기 도구:** 선택 도구(영역 선택), 연필, 브러시, 지우개, 채우기(고속 Flood Fill), 스포이드, 텍스트
* **도형 도구:** 직선, 직사각형, 둥근 직사각형(네 모서리가 모두 완벽히 둥근 대칭 사각형), 타원 (실시간 프리뷰 지원)
* **글자(텍스트) 도구:** 또렷하고 올바르게 정방향으로 서 있는 한국어 '가가' 타이포그래피 벡터 아이콘 적용
* **색상 팔레트:** Color 1(전경색) / Color 2(배경색) 및 윈도우 11 그림판 표준 20색 그리드 + 시스템 컬러 피커 연동

### 8. 스캔라인 페인트통 & 고해상도 적응형 메모리 보호
* **초고속 스캔라인 Flood Fill (스마트 페인트통):** 가로 스팬(Span) 단위 스캔 및 1픽셀당 1비트 비트셋 방문 추적을 도입하여, 4K 초고해상도 캔버스에서도 메모리를 1MB 미만으로 극소화하며 프레임 드랍 없이 순식간에 영역을 채웁니다.
* **해상도별 적응형 Undo 스택:** 캔버스 해상도에 맞춰 실행 취소 스냅샷 보존 단계를 지능적으로 스케일링(일반: 35단계, 4K: 12단계)하여 장시간 고화질 사진 편집 시에도 맥의 메모리 압박을 원천 방지합니다.
* **자동화 단위 테스트(Unit Tests):** `swift test`를 통한 핵심 캔버스 엔진, 오프셋 방향 리사이징, Undo/Redo 생명주기 및 픽셀 매칭 단위 테스트 100% 무결점 통과.

### 9. 고화질 macOS 앱 아이콘 (.icns) & `/Applications` 지원
* 최신 macOS Squircle(둥근 사각형) 규격에 Windows 11 그림판 팔레트와 붓 3D 에셋을 결합한 고화질 Retina `.icns` 탑재 (16x16 ~ 1024x1024 멀티스케일).
* `/Applications` 폴더에 설치되어 Spotlight(`⌘Space`) 및 런치패드에서 일반 앱처럼 바로 실행 가능.

### 10. 단축키 요약
* `⌘N`: 새 캔버스 만들기
* `⌘O`: 이미지 파일 열기
* `⌘I`: 외부 이미지 얹기 (삽입)
* `⌘S`: 캔버스 저장 (PNG, JPEG)
* `⇧⌘S`: 다른 이름으로 저장 (새 파일명/경로 지정)
* `⌘W`: 현재 작업 창/도화지만 닫기 (변경사항 존재 시 저장 확인 대화상자 호출, 프로그램 본체는 Dock 및 상단 메뉴바에 상주 유지)
* `⌘Q`: 프로그램 완전 종료 (변경사항 존재 시 저장 확인 대화상자 호출)
* `⌘K`: 캔버스 크기 및 방향별 여백 확장 설정
* `⌘Z`: 실행 취소 (Undo)
* `⇧⌘Z`: 다시 실행 (Redo)
* `⌘X`: 선택 영역 잘라내기
* `⌘C`: 선택 영역 복사
* `⌘V`: 클립보드 이미지 붙여넣기
* `Delete` / `Backspace`: 선택 영역 삭제
* `⌘A`: 캔버스 전체 선택 (또는 텍스트 박스 내 전체 선택)
* `방향키`: 선택 영역 1px 이동 (`Shift` 조합 시 10px 이동)
* `Enter`: 선택 영역 캔버스에 영구 병합
* `⌘+` / `⌘-`: 캔버스 확대 / 축소
* `⌘0`: 100% 원래 크기
* `⌘B`: 텍스트 굵게 (Bold)
* `⌘I`: 텍스트 기울임꼴 (Italic)
* `⌘U`: 텍스트 밑줄 (Underline)
* `⌘T`: 시스템 서체(글꼴) 패널 열기

## 🚀 맥(macOS)에서 빌드 및 실행하는 방법

macOS 12.0 (Monterey) 이상, Apple Silicon (M1/M2/M3/M4/M5) 및 Intel 지원.

### 방법 1. `/Applications/`에서 실행 (가장 추천)
```bash
open /Applications/kMacPaint.app
```
또는 Spotlight(`⌘ + Space`)에서 **kMacPaint** 검색 후 실행.

### 방법 2. 프로젝트 빌드 스크립트 실행
```bash
cd "/Users/inkeunkang/Library/CloudStorage/GoogleDrive-gemus.kik@gmail.com/내 드라이브/종합집계_260416/Tools_툴즈_260715/261118_맥_그림판_mspaint"
chmod +x build_app.sh
./build_app.sh
```
> 빌드가 완료되면 `kMacPaint.app` 번들이 생성되며 `/Applications/`에 자동 덮어쓰기 복사됩니다.

### 방법 3. 터미널 개발 모드 실행 (`swift run`)
```bash
swift run
```

## 📦 다른 사람에게 전달 및 배포하는 방법

맥 앱(`.app`)은 내부적으로 폴더 번들 구조이므로, 다른 사람에게 이메일, 카카오톡, 슬랙 등으로 전달할 때는 **`kMacPaint.zip` 압축 파일**을 전달해야 파일이 손상되지 않습니다.

### 1. 배포 파일 생성
```bash
# macOS ditto 명령어로 권한 및 리소스를 완벽 보존한 압축 파일 생성 (약 3.3MB)
ditto -c -k --sequesterRsrc --keepParent kMacPaint.app kMacPaint.zip
```
> 이미 프로젝트 폴더에 `kMacPaint.zip`이 생성되어 있으므로 이 파일만 상대방에게 전달하면 됩니다.

### 2. 받는 사람 안내 가이드
1. 받은 `kMacPaint.zip`을 더블클릭하여 압축 해제합니다.
2. 나온 `kMacPaint.app`을 맥의 **[응용 프로그램] (Applications)** 폴더로 드래그합니다.
3. 앱을 실행합니다.

> **💡 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨는 경우:**  
> 앱 아이콘에서 **마우스 우클릭 > [열기]**를 누른 뒤 대화상자에서 **[열기]**를 한 번만 클릭하면 이후부터는 더블클릭으로 바로 실행됩니다. (또는 시스템 설정 > 개인정보 보호 및 보안 > [확인 없이 열기] 클릭)
